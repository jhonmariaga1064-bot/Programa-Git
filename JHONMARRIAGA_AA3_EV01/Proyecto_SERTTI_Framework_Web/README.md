# Proyecto_SERTTI_Framework_Web

Módulo web de gestión de trámites para **SERTTI Tránsito La Jagua**, codificado con el framework **Spring Boot 3**, **Spring Data JPA** y almacenamiento en base de datos **MySQL** para la evidencia **GA7-220501096-AA3-EV01**.

## Cumplimiento técnico
- **Framework seleccionado:** Spring Boot 3 (Spring Web MVC + Spring Data JPA).
- **Almacenamiento de datos:** MySQL (`sertti_tramites_db`) con mapeo ORM mediante entidad `Tramite` y repositorio `TramiteRepository`.
- **Estándar de codificación y comentarios:** Convenciones oficiales de Java (`PascalCase` en clases, `camelCase` en métodos/variables, paquetes en minúsculas `com.sertti.tramites.*`) y documentación Javadoc en todas las clases y métodos.
- **Control de versiones:** Git y GitHub (`https://github.com/jhonmariaga1064-bot/Programa-Git`).
